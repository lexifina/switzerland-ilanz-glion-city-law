# Art. 23 Gebühr für die exklusive Nutzung
1 Folgende monatlichen Gebühren gelten für die exklusive Nutzung von Parkplätzen:
a. Tiefgaragenparkplatz 110 Franken;
b. Garagenbox 110 Franken;
c. Gedeckter Parkplatz 80 Franken;
d. Aussenparkplatz 60 Franken.
2 Aussenparkplätze ohne befestigten Untergrund können in den Fraktionen (ohne Stadt Ilanz) gegen eine Gebühr von 30 Franken pro Monat mittels einer Vereinbarung zur exklusiven Nutzung überlassen werden.
3 Aussenparkplätze ohne befestigten Untergrund können auf Stadtgebiet von Ilanz gegen eine Gebühr von 50 Franken pro Monat mittels einer Vereinbarung zur exklusiven Nutzung überlassen werden.
4 Für die gewerbliche Nutzung von Parkplätzen kann die Geschäftsleitung abweichende monatliche Gebühren festlegen.
